# 新手如何购买属于自己的域名

域名是你网站在互联网上的"门牌号"。没有域名，用户只能通过 IP 地址（比如 `142.250.80.46`）来访问你的网站，既难记又不专业。拥有一个好域名，是建站的第一步。

## 什么是域名？先了解几个概念

在购买域名之前，先搞清楚几个常见的名词：

| 名词 | 解释 | 示例 |
|------|------|------|
| **域名（Domain）** | 完整的网站地址 | `google.com` |
| **顶级域（TLD）** | 域名最后那部分 | `.com`、`.cn`、`.xyz` |
| **二级域** | 顶级域前面的部分 | `google` |
| **子域名** | 主域名前面加前缀 | `mail.google.com` |
| **DNS** | 域名解析系统，把域名转成 IP | `8.8.8.8` |
| **WHOIS** | 域名的注册信息公开查询 | — |

简单来说，域名就是把一串难记的 IP 地址，变成一个好记的名字。

## 怎么选一个好域名？

一个好的域名应该遵循以下几个原则：

- **短**：越短越好记，理想长度在 6~15 个字符
- **好拼**：别人听完就知道怎么打出来，避免数字谐音（比如用 `4` 代替 `for`）
- **有意义**：能让人联想到你的网站内容或品牌
- **优先选择 `.com`**：这是全球认知度最高的顶级域，也是默认的选择

::: tip 小贴士
如果你的首选域名被抢注了，可以试试加个后缀词（如 `getxxx.com`、`xxxapp.com`），或者换个顶级域（`.me`、`.xyz`、`.cc` 也是很多独立开发者喜欢的选择）。
:::

## 常见的域名后缀怎么选？

| 后缀 | 用途 | 参考年价 | 推荐度 |
|------|------|----------|--------|
| **`.com`** | 商业/通用 | $10~15 | ★★★★★ |
| **`.xyz`** | 通用（便宜） | $1~2 | ★★★★ |
| **`.me`** | 个人博客 | $15~20 | ★★★★ |
| **`.cn`** | 中国 | ¥30~50 | ★★★ |
| **`.top`** | 通用（便宜） | $2~5 | ★★★ |
| **`.dev`** | 开发者 | $12~18 | ★★★ |
| **`.site`** | 通用 | $2~5 | ★★★ |

新手建议**首选 `.com`**，预算有限用 `.xyz` 或 `.top` 先跑起来也没问题。

## 域名注册商推荐

域名的价格和服务因注册商而异。有些厂商首年特别便宜，但续费偏贵，需要留意。

| 注册商 | 特点 | 适合人群 |
|--------|------|----------|
| **Cloudflare** | 成本价销售，无加价续费 | 想省钱的用户 |
| **Namecheap** | 老牌注册商，免费 WHOIS 隐私保护 | 新手首选 |
| **Namesilo** | 价格透明，免费隐私保护 | 长期持有 |
| **GoDaddy** | 全球最大，但套路多（加价续费、捆绑销售） | 不推荐新手 |
| **阿里云/腾讯云** | 国内注册方便，需实名认证 | 国内用户 `.cn` 域名 |
| **Porkbun** | 价格实惠，界面清新 | 国外用户 |

::: warning 注意
国内注册商（阿里云、腾讯云等）购买域名需要实名认证。如果你希望匿名注册，推荐使用 Cloudflare 或 Namecheap，它们都提供免费的 WHOIS 隐私保护。
:::

## 实战：在 Namecheap 购买域名

下面以 **Namecheap** 为例，带你走一遍完整的购买流程。

### 1. 注册账号

打开 [Namecheap 官网](https://www.namecheap.com)，点击右上角的 **Sign Up** 注册一个新账号。填好邮箱、用户名和密码即可，也可以用 Google/GitHub 账号直接登录。

### 2. 搜索域名

在首页的搜索框中输入你想要的域名，点击搜索：

- 如果域名**可以注册**，会直接显示价格和"Add to cart"按钮
- 如果域名**已经被注册**，会显示"Taken"，并推荐一些相近的可选域名

::: tip 搜索技巧
可以一次搜多个关键词，Namecheap 会自动帮你排列组合，有时候能发现惊喜。
:::

### 3. 加入购物车并结算

找到心仪的域名后，点击 **Add to cart**，然后进入购物车。

在结算页面需要注意几个选项：

- **Domain Privacy（域名隐私保护）**：Namecheap 免费提供，**一定要勾上**。开启后，别人查 WHOIS 看不到你的真实姓名和邮箱
- **Registration Period（注册年限）**：默认 1 年，建议一次性注册 2~5 年（更省心，也能避免忘记续费导致域名被别人抢走）
- **Auto-Renew（自动续费）**：建议开启，防止域名过期

### 4. 支付

支持信用卡、PayPal 和支付宝等多种支付方式。填好支付信息，确认订单金额无误后，点击支付即可。

### 5. 验证邮箱

支付完成后，Namecheap 会发一封验证邮件到你注册的邮箱。**务必完成验证**，否则域名在一定时间后可能被冻结。

## 买完域名后要做什么？

### 设置 DNS 解析

域名买好之后，需要把它指向你的服务器 IP，这样用户访问域名时才能看到你的网站。

以 Namecheap 为例：

1. 登录后进入 **Dashboard**，找到刚刚购买的域名，点击 **Manage**
2. 切换到 **Advanced DNS** 标签
3. 添加一条 **A 记录**：

| 类型 | 主机 | 值 | TTL |
|------|------|-----|-----|
| A Record | @ | 你的服务器 IP | Automatic |
| A Record | www | 你的服务器 IP | Automatic |

- `@` 表示根域名（`你的域名.com`）
- `www` 表示带 www 的子域名（`www.你的域名.com`）

::: tip DNS 生效时间
DNS 修改后不是立即生效的，需要等待 DNS 缓存过期（通常几分钟到几小时不等，一般 10~30 分钟内全球生效）。
:::

### 理解常见的 DNS 记录类型

| 记录类型 | 作用 | 示例 |
|----------|------|------|
| **A** | 将域名指向一个 IPv4 地址 | `123.45.67.89` |
| **AAAA** | 将域名指向一个 IPv6 地址 | `2001:db8::1` |
| **CNAME** | 将域名指向另一个域名 | `www` → `你的域名.com` |
| **MX** | 邮件服务器记录 | 配置企业邮箱时使用 |
| **TXT** | 文本记录（常用于验证所有权、SPF） | `google-site-verification=xxx` |

大多数个人博客场景下，只需要设置 A 记录就够了。

### 绑定到 VPS

假设你已经有了一台 VPS（比如之前教程搭建的），并且 Nginx 已经在运行。让域名指向你的 VPS：

```bash
# 编辑 Nginx 配置文件
nano /etc/nginx/sites-available/你的域名.com
```

添加以下配置：

```nginx
server {
    listen 80;
    server_name 你的域名.com www.你的域名.com;

    root /var/www/html;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

启用站点并重载 Nginx：

```bash
ln -s /etc/nginx/sites-available/你的域名.com /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx
```

### 免费申请 SSL 证书（HTTPS）

没有 HTTPS 的网站，浏览器会显示"不安全"，强烈建议配置 SSL 证书。使用 `acme.sh` 可以免费申请：

```bash
# 安装 acme.sh
curl https://get.acme.sh | sh

# 申请证书
~/.acme.sh/acme.sh --issue -d 你的域名.com -d www.你的域名.com -w /var/www/html

# 安装证书到 Nginx
~/.acme.sh/acme.sh --install-cert -d 你的域名.com \
  --key-file /etc/nginx/ssl/key.pem \
  --fullchain-file /etc/nginx/ssl/cert.pem \
  --reloadcmd "systemctl reload nginx"
```

## 域名续费与防丢指南

::: danger 重要
域名忘记续费，被别人抢走，就再也要不回来了。很多灰产专门盯着过期域名抢注，然后高价卖回给你。
:::

- **开启自动续费**：大多数注册商都支持，绑定信用卡或 PayPal
- **一次多买几年**：`.com` 最多可以一次性注册 10 年，省心
- **关注续费价格**：很多注册商首年便宜但续费翻倍，买之前先看看续费价
- **绑定多个邮箱**：确保能收到续费提醒邮件
- **锁定域名**：在域名管理后台开启注册商锁定（Registrar Lock），防止域名被未经授权转出

## 小结

买一个域名并不复杂，整个流程总结下来就是：

1. 想好一个简短、好记的域名
2. 选一个靠谱的注册商（推荐 Namecheap 或 Cloudflare）
3. 搜索、下单、付款
4. 设置 DNS 解析，把域名指向你的服务器
5. 配置 SSL 证书，开启 HTTPS
6. 开启自动续费，防止域名过期

有了域名和 VPS，你的个人网站就算是"拎包入住"了。下一步，就是往里面装内容了。祝你拥有一个称心如意的域名！
